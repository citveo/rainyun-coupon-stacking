## 三个容易被忽略的限制

**湖北节点不能用优惠券。** 受最低限价政策影响，湖北十堰的机器无法使用优惠券，其他区域正常。退款政策在湖北节点照样适用。冲着 5 折去下单，结果选了湖北，券用不上。

**退款只退到账户余额。** 新购产品支持 7 天无理由退款，在控制面板自助操作，每个账号限 3 次，钱退回账户余额而不是原支付渠道。领过消费返利积分的订单不支持退订，日付产品、流量包、IP、升级类订单也不支持。1 元试用同样不在无理由退款范围内。

**P40 是 NAT 机型，没有独立公网 IP。** 只提供 10 条端口转发，要独立 IP 得另外加购。如果打算对外提供 Web 服务或者需要固定入口，这一条会直接改变你的选型，别只看 168 元的价格。RTX 3080 是广州番禺节点，三网平均延迟约 32ms，广东电信可到 3ms。
